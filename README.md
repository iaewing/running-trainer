# Running Trainer

Mobile-first adaptive running plan app for 10K and half-marathon training.

## Direction

V1 is an iOS-focused React Native app backed by a Laravel API. The product starts with fast manual run logging, HealthKit import, and adaptive plans that respond to missed runs, effort, illness, travel, and other life interruptions.

The repository is intended to be a monorepo while the product is personal-first and early-stage:

- `apps/mobile` - React Native iOS app
- `apps/api` - Laravel API
- `docs` - product, implementation, and architecture notes

See [docs/implementation-plan.md](docs/implementation-plan.md) for the current plan.
See [docs/status.md](docs/status.md) for current execution status.
